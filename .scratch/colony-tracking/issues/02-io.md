# 02: `io` module — discovery, parsing, shared I/O, legacy mapping

Goal: the shared input/output layer every stage builds on, plus the synthetic
test fixtures the whole suite needs.

Spec: `.scratch/colony-tracking/spec.md` — "I/O contract" (all of it), and
the per-stage output sections for what io must read/write. Reference
implementation for the parsing conventions:
`/home/kriedmiller/projects/colony_size/prototype/make_difference_images.py`
(flat-layout parsing), `prototype/segment_growth_pipeline.py` (both layouts,
label/CSV/marker I/O), `prototype/growth_analysis.py` (geometry CSV, legacy
column names). Real data to eyeball (READ-ONLY, never modify):
`/home/kriedmiller/projects/colony_size/prototype/data/`.

## Build — `src/colony_tracking/io.py`

- **Input-tree discovery** accepting BOTH layouts (spec "I/O contract →
  Input tree"):
  - *flat*: all wells' frames in one directory; well = leading `-<A-H>\d{3}`
    of the file name (e.g. `-A001--PO01--LO005--...tif`);
  - *per-well*: one subdirectory per well; well = the directory name.
  - Return a well → frames structure; frames sorted by frame number.
- **File-name parsing** (both layouts): frame number from `LO<nnn>` (1-based
  int), acquisition time from the `T<digits>` field (raw value, int), well
  field. Expose small pure functions so tests can drive them on strings.
- **Shared 1/99 percentile stretch**: uint16 (or any float) image → uint8
  via 1st/99th percentile clip. Pure function on arrays.
- **128-neutral difference mapping** (spec: "the shared 1/99 percentile
  stretch" lives here; the 128 mapping is its sibling):
  `map_to_uint8(diff, limit) = 128 + diff * 127 / limit`, clamped to 0..255;
  plus a `display_limit(diff, percentile, subsample)` helper: the
  `display_percentile` percentile of |diff| estimated on the subsampled grid
  (stride `subsample`).
- **Label image I/O**: write uint32 label TIFFs (0 = background, colony IDs);
  read them back.
- **colonies.csv I/O**: canonical columns
  `well, frame, t_seconds, image, colony_id, group_id, merged_with,
  pre_existing, area_px, centroid_y, centroid_x`. Writer takes rows; reader
  returns canonical rows and **maps legacy prototype column names**:
  `lo` → `frame`, `n_merged` → `ancestors`, `max_n_merged` →
  `max_ancestors`, `first_lo` → `first_frame`, `last_lo` → `last_frame`,
  `rim_excluded_lo` → `rim_excluded_frame` (see the prototype's
  `data/analysis/*/trajectories.csv` for real legacy rows). New writes always
  use canonical names.
- **Done marker I/O**: per-well `_done.txt`, tab-separated `key\tvalue`
  lines; canonical segment keys: `frames, groups, colonies,
  pre_existing_colonies, merge_events, forked_segments, discarded_instances`.
  Reader returns a dict (tolerate missing keys); writer takes a dict.
- **scale.txt I/O** (difference output, per well): key/value lines; the
  writer writes `reference` (reference frame file name) and
  `display_limit_int16` (float). Reader tolerates missing or extra lines
  (prototype trees also carry `flatfield`/`sigma`).
- **well_geometry.csv I/O**: `well, cy, cx, R` (R one decimal), read/update
  of the shared cache in the analysis out root.
- No option/function may default to a data path; every path is an explicit
  argument. No prints; log via the package logger where runtime happens.

## Build — `tests/conftest.py` fixtures (needed by tickets 03, 04, 06, 07)

- **Synthetic mini-plate builder** (lazy factory function, e.g.
  `build_mini_plate(tmp_path, layout, ...)`): 2–3 wells × 5–8 frames of
  **2048×2048 uint16** (the circle-fit constants assume the real plate size —
  do not shrink). Frame names follow the real acquisition vocabulary:
  `-<A-H>\d{3}--PO01--LO<nnn>--CO1--SL001--PX32500--PW0050--IN0020--TM<n>
  --X014222--Y011210--Z220046--T<ms>--WE00001.tif` with **millisecond** `T`
  fields (e.g. 0, 3600000, 7200000, ...). Plant (see spec "Fixtures"):
  - a dark meniscus ring at R ≈ 920 px (centre ≈ image centre) in the
    earliest frames — visible enough for the circle fitter, faint/noise in
    later frames is fine;
  - planted growing disks: a pair that grows until it touches (→ merge), a
    static disk (→ `no_growth`), one present from frame 1 (→ `from_start`),
    one approaching the rim (→ rim exclusion). Disks grow smoothly (exponential
    where useful so rate tests have a known slope).
  - Emit in BOTH flat and per-well layouts on request; keep parameters
    (wells, frames, disk positions, ring R) overridable so later tickets can
    build targeted plates.
- A helper to build **synthetic label series** (integer label TIFFs + an
  in-memory frame list) for tracking/segmentation tests — no model involved.
- Keep per-test construction lazy (function-scoped) — a full 3×8 2048² plate
  is ~190 MB; tests should build only what they need.

## Tests — `tests/test_io.py`

- Discovery in both layouts (flat well parsing from names; per-well dir
  names; frame ordering).
- Parsing: `LO` frame number, `T` field, well field on realistic names.
- 1/99 stretch against known values; 128-neutral mapping against known
  values (0 diff → 128; known count × known limit → known byte; clamping);
  display-limit helper on a known distribution.
- scale.txt / marker / colonies.csv write→read round-trips; scale reader
  tolerates extra legacy lines; marker reader tolerates missing keys.
- Legacy mapping: read a prototype-style CSV (write one with `lo`, `n_merged`,
  `max_n_merged`, `first_lo`, `last_lo`, `rim_excluded_lo` in the test) →
  canonical columns, values unchanged.
